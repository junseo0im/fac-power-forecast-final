# 부록: 1시간 최대 전력 예측 파이프라인

본 분석(15분 전력 예측)과 별도로, **1시간 단위 최대수요전력을 직접 예측**하고 **다음 시간에 피크가 올 확률**을 추정한 파이프라인입니다. 15종 이상의 모델을 같은 검증 구조에서 비교했습니다.

> 이 파이프라인은 1~8월 전체로 학습했습니다. 이후 본 분석의 데이터 진단에서 1~6월에 반복 기록이 많다는 것이 확인되었으므로, 결과는 참고용으로 봅니다. 본 분석의 결론은 저장소 루트의 노트북을 따릅니다.

## 문제 설정

| 트랙 | 예측 시점 | 예측 대상 | 쓸 수 있는 정보 |
|---|---|---|---|
| A (실시간 경보) | 매 정시 | 다음 1시간의 최대수요전력 | 직전 시각까지의 값 |
| B (익일 계획) | 매일 00시 | 그날 24시간의 시간별 최대 | 전날 23:59까지의 값 |

| 시나리오 | 추가 정보 | 가정 |
|---|---|---|
| S0 | 달력·과거 전력 | 항상 알 수 있음 (기준) |
| S1 | S0 + 당일 생산계획 합계 | 전날 생산계획이 확정됨 (대표 결과) |
| S2 | S1 + 당일 가동 여부 | 가동 캘린더를 공유함 (상한) |

- **검증**: 2주씩 6개 구간(F1 06/09 ~ F6 08/31)을 시간순으로 검증하고, 테스트(9/1~9/14)는 마지막에 한 번만 평가했습니다.
- **피크 기준**: 각 구간 학습 기간의 상위 5% 값(약 181~187kW)
- **정보 누설 점검**: 예측 시점 이후의 전력·기상·가동 여부를 난수로 바꿔도 예측이 변하지 않는지 확인합니다(`power_utils/features.py`).

## 비교한 모델

| 계열 | 모델 |
|---|---|
| 단순 기준 | 직전 값, 지난주 같은 시각, 최근 4주 평균 |
| 가이드북 기준선 | SimpleRNN, 랜덤 포레스트 (가이드북 오류 수정 후 재평가) |
| 통계 | MSTL, AutoARIMA |
| 트리 앙상블 | LightGBM(피크 가중·분위수 포함), XGBoost, CatBoost (Optuna 튜닝) |
| 딥러닝 | NHITS, LSTM, TFT |
| 사전학습 | Chronos-2 (zero-shot, 공변량), Chronos-2-small 미세조정 |
| 결합 | NNLS 가중 앙상블, 컨포멀 예측구간, isotonic 확률 보정 |
| 확장 실험 | Chronos-2 임베딩 + 분류기 (피크 위험 확률) |

## 주요 결과 (테스트 9/1~9/14, 단위 kW)

| 트랙 | 모델 | MAE | RMSE | 피크 시간 MAE | 피크 F1 |
|---|---|---|---|---|---|
| A | 지난주 같은 시각 | 7.66 | 10.32 | 9.89 | 0.33 |
| A | 가이드북 RNN | 6.79 | 9.41 | 12.00 | 0.18 |
| A | LightGBM (S1) | 6.04 | 10.14 | 7.37 | 0.49 |
| A | **Chronos-2 zero-shot (선정)** | **5.20** | **6.93** | **6.72** | 0.39 |
| A | 최종 앙상블 (S1) | 5.06 | 6.74 | 7.30 | 0.57 |
| B | 지난주 같은 시각 | 7.66 | 10.32 | 9.89 | 0.33 |
| B | **Chronos-2 + 공변량 (선정)** | **5.89** | **8.01** | **8.89** | 0.21 |
| B | 최종 앙상블 (S1) | 5.79 | 7.95 | 7.35 | 0.55 |

모델 선정은 테스트 전에 검증 구간 성능, 추론 시간, 단순함을 기준으로 정한 규칙을 따랐습니다(`outputs/tables/selection_table.csv`). 전체 결과는 `outputs/tables/M36_test_scores.csv`에 있습니다.

## 구성

| 경로 | 내용 |
|---|---|
| `notebooks/resource_optimization_baseline.ipynb` | KAMP 분석실습 가이드북 예제 코드 실행과 오류 수정 (출처는 노트북 첫 셀 참고) |
| `notebooks/01_학습_파이프라인.ipynb` | 단계별 학습·추론 실행 (`scripts/*.py` 호출) |

| `notebooks/03_AI_확장실험.ipynb` | Chronos-2 임베딩으로 피크 위험 확률 개선 실험 |
| `power_utils/` | 공통 함수 (데이터, 피처, 검증 구간, 모델, 평가, 앙상블) |
| `scripts/` | 단계별 학습 스크립트 |
| `outputs/tables/`, `outputs/figures/` | 결과표(M01~M38, X01~X08)와 그림 |
| `outputs/logs/` | 학습 곡선·튜닝 기록 |
| `outputs/models/step6_final_config.pkl` | STEP 6에서 정한 앙상블 가중치·보정·임계값 설정 (`scripts/predict_test.py`가 읽음, 같은 내용의 요약은 `outputs/tables/step6_final_config.json`) |

## 실행

저장소 루트에서 `python run_all.py --appendix`로 함께 실행하거나, 이 폴더에서 직접 실행합니다.

```
python run_all.py --mode full             # 저장된 학습 결과로 노트북 다시 실행 (약 1분)
python run_all.py --mode full --retrain   # 모든 모델 다시 학습 (CPU 기준 하루 이상)
```

실제 전력값이 들어 있는 예측 파일(`outputs/preds/`, `outputs/submission/`)은 저장소에 올리지 않았습니다. 이 파일이 필요한 셀은 다시 학습해야 실행됩니다.
