# 실행과 재현성

## 실행 방법

1. **환경**(Python 3.12.14, CPU)
   ```
   python -m venv .venv
   .venv/Scripts/python -m pip install -r requirements.txt      # macOS·Linux: .venv/bin/python
   ```
   conda를 쓰면 `conda env create -f environment.yml`.
2. **전체 실행**(프로젝트 루트에서)
   ```
   python run_all.py                  # 01-1 → 06 노트북을 처음부터 실행(02-1·02-1b·02-1c는 저장된 예측 사용)
   python run_all.py --with-chronos   # 02-1·02-1b·02-1c의 예측도 다시 계산(CPU로 수 시간)
   python run_all.py --appendix       # 부록 노트북도 저장된 결과로 다시 실행
   python run_all.py --check          # 실행 전후 결과표 비교
   ```
   - Chronos-2 가중치(`amazon/chronos-2`, `autogluon/chronos-2-small`)는 처음 쓸 때 Hugging Face에서 받습니다(`--with-chronos`, `--appendix`에 인터넷 필요). 미리 받아 두려면
     `python -c "from huggingface_hub import snapshot_download as d; d('amazon/chronos-2'); d('autogluon/chronos-2-small')"`
   - `run_all.py`는 노트북을 자기를 실행한 파이썬(위에서 만든 환경)으로 돌립니다.
3. **부록 모델 재학습**(선택, CPU 기준 하루 이상): `appendix/hourly_max_pipeline/run_all.py --mode full --retrain`

**실행 시간**(`python run_all.py --appendix --check`, Intel Core i5-1135G7 4코어 노트북·RAM 8GB·GPU 사용 안 함, Windows 11, Python 3.12.14, 스레드 4) — 전체 9.6분

- 기본 실행은 02-1·02-1b·02-1c를 건너뛰고 저장된 예측을 씁니다. 02-1의 15분 Chronos-2 예측은 Python 3.11.9 환경에서 계산한 것이고, 02-1b는 모델별로 계산해 둔 결과를 불러옵니다(계산 시간은 노트북 3절 표). 02-1c는 Python 3.12.14에서 다시 실행했습니다(4코어 노트북 CPU에서 미세조정 78분 + 예측 24분, LoRA 확인 출력 포함).
- 시간 최대 분석(02-4)은 `outputs/preds/`가 없으면 Chronos-2 예측과 주별 학습을 새로 계산하고, 있으면 저장된 예측을 씁니다.
- 부록 노트북은 저장된 학습 결과를 읽어 표·그림을 다시 만듭니다. 모든 모델을 다시 학습하는 데 걸린 시간은 부록 노트북 01의 첫 셀 표에 단계별로 적혀 있습니다.

## 재현성

- 난수 seed를 고정했습니다(15분 분석 42, 시간 최대 분석 `[42, 2021, 2024, 2025, 2026]`). Chronos-2 가중치는 `amazon/chronos-2`(1억 2천만 파라미터), `autogluon/chronos-2-small`(2천8백만 파라미터)을 씁니다.
- 06 노트북이 입력 데이터의 SHA-256을 확인하고, 제출 파일에서 다시 계산한 지표가 02-4의 표와 같은지 `assert`로 확인합니다.
- `tests/`: 정보 누설(정답에서 계산된 열 사용 금지, 시험 주 이전 자료만으로 예측 재현, 미래 값 교란 검사), 평가 범위, 도우미, 제출 파일 점검.

**실행 확인 결과**(위 명령, `outputs/run_all_summary.json`)
- 모든 노트북이 오류 없이 실행되었습니다(02-1·02-1b·02-1c는 저장된 예측 사용).
- 실행 전후 비교: 본문 표 71개 중 값이 달라진 표 0개, 새 표 2개(t57, t58). 6개 표(e08, e09, h01, h04, h05, r01)는 숫자가 상대오차 1e-9 안(실제 최대 약 1e-13)에서만 달랐습니다. 이전 확인 PC(AMD CPU, Python 3.11.9)와 CPU·파이썬 버전이 달라 생긴 부동소수점 차이로, 반올림해 보고하는 값은 모두 같습니다.
- 부록 표 73개 중 달라진 표 0개. 부록 표 M24(추론 시간)는 전체 재학습 때(AMD Ryzen 5 5600) 잰 값이며, 장치 열도 그 기록에서 읽습니다.
- `tests/` 18개 통과(pytest 9.1.1).
