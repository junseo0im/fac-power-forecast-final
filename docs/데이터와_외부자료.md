## 공개 저장소에서 뺀 파일

대회 제출 zip에는 들어 있지만, 원자료 재배포를 피하려고 이 저장소에서는 뺀 파일입니다. 원자료를 넣고 `run_all.py`를 실행하면 다시 만들어집니다.

| 뺀 파일 | 이유 |
|---|---|
| `data/raw/`, `data/processed/` | 출제 데이터와 그 전처리 결과 (받는 방법: [data/README.md](../data/README.md)) |
| `data/external/` | 외부 공개 자료(CC BY 4.0). 출처에서 받는 방법은 [data/README.md](../data/README.md) |
| `outputs/predictions/`의 `final_*`, `pred_*`, `test_predictions.csv`, `decision_log.csv`, `outputs/preds/` | 실제 전력값이 함께 들어 있음 (예측값만 있는 `chronos_*`, `extra_*`는 올림) |
| 부록 `outputs/preds/`, `outputs/submission/`, 표 `step6_*`·`shap_features_*` | 실제 전력값이 함께 들어 있음 |

노트북 중 원자료 행이 그대로 보이는 셀 몇 개는 출력을 지웠습니다. 부록 노트북을 저장된 결과로 다시 실행하려면 위 부록 파일이 필요하므로, 제출 zip을 쓰거나 부록 파이프라인을 다시 학습해야 합니다.
